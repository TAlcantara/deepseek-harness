# 路线图、需求孵化与现状梳理

[English](README.md) | 中文

本目录是仓库中状态与方向类文档的唯一归宿：项目现状如何、正在酝酿什么、未来将走向何方。描述当前机制的参考文档遵循[文档标准](../AGENTS.md)，决策记录由 [Agent Note](../../.agents/notes/README.zh.md) 承载；设立本层是为了让状态类和前瞻类材料不必伪装成其中任何一种。撰写规则见 [AGENTS.md](AGENTS.md)。

## 现状梳理

`surveys/` 存放项目或子系统现状的时点分析：缺口、风险与跨模块观察。梳理以 `YYYY-MM-DD-<主题>.md` 命名，并在头部锚定所分析的 commit，用 `git diff` 对照锚点即可证明内容是否仍然适用。写错的断言可原地修正；代码发生变化则需要新建带日期的梳理并取代旧篇。

暂无现状梳理。

## 需求孵化

`incubation/` 存放仍在打磨中的需求草案。每份草案要么毕业为 proposed（已提议）Agent Note 或已交付的改动，要么被放弃——被放弃的草案若分析仍有价值，则冻结保留并在顶部标注状态。

暂无孵化中的需求。

## 路线图

`roadmaps/` 存放按主题组织的 Now/Next/Later 轻量状态板：每个条目一行，带状态和指向草案、Note 或已交付改动的链接——只表达意图，永不构成承诺。

暂无路线图。
