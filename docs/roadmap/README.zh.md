# 路线图、需求孵化与现状梳理

[English](README.md) | 中文

本目录是仓库中状态与方向类文档的唯一归宿：项目现状如何、正在酝酿什么、未来将走向何方。描述当前机制的参考文档遵循[文档标准](../AGENTS.md)，决策记录由 [Agent Note](../../.agents/notes/README.zh.md) 承载；设立本层是为了让状态类和前瞻类材料不必伪装成其中任何一种。撰写规则见 [AGENTS.md](AGENTS.md)。

## 现状梳理

`surveys/` 存放带日期的项目或子系统现状快照分析：缺口、风险与跨模块观察。每篇梳理是以 `YYYY-MM-DD-<主题>.md` 命名的快照；同一主题的新梳理取代旧梳理。

暂无现状梳理。

## 需求孵化

`incubation/` 存放仍在打磨中的需求草案。每份草案要么毕业为 proposed（已提议）Agent Note 或已交付的改动，要么被放弃；无论哪种结果，其文件都随结果落地而移出本目录。

暂无孵化中的需求。

## 路线图

`roadmaps/` 存放按主题组织、持续更新的方向性文档：优先级与推进顺序的意图，永远不构成承诺。

暂无路线图。
