# Agent Note: 面向状态与方向文档的 roadmap 文档层

Status: implemented

[English](2026-09-22-docs-roadmap-tier.md) | 中文

## 问题

[文档层级体系](../../../../docs/AGENTS.md)为每类正式文档指定了唯一归宿，但这些归宿全部用于容纳当前机制的描述、决策记录、事故复盘、操作步骤或产品指南。项目现状的时点梳理、尚未形成决策的需求草案、以及主题路线图没有正式归宿：slop 清单拒绝在机制文档中标注状态，因此这类材料要么违反文档标准，要么只能留在未提交的本地草稿中，对团队不可见，也无法被正式文档链接。本地草稿的忽略名 `local-doc` 同样无法表明其中应放什么。

## 决策

- **`docs/roadmap/` 成为状态与方向文档层**，包含三类文档，各自拥有一个随首篇文档创建的子目录。`surveys/` 存放带日期的快照（`surveys/YYYY-MM-DD-<主题>.md`），落地后不再原地修改；同一主题的新快照取代旧快照，并在旧文件中添加指向行。`incubation/` 存放以 `Status: incubating` 开头的需求草案；草案是短期的，当其毕业为 `proposed/`（已提议）Agent Note 或已交付改动、或被放弃时，其文件即移出该目录——值得保留的放弃理由记录为 `rejected/`（已否决）Agent Note。`roadmaps/` 存放按主题组织、持续更新的方向性文档，只表达意图，永远不构成承诺；条目落地为具体工作时，以 `proposed/` Agent Note 或已交付改动的形式离开路线图。
- **撰写规则见 [docs/roadmap/AGENTS.md](../../../../docs/roadmap/AGENTS.md)**，与其他代理指令文件一样仅维护英文，并列入配对清单的排除项；双语 [README](../../../../docs/roadmap/README.zh.md) 面向读者提供导引并索引当前文档，每篇文档一行，与文档在同一改动中更新。
- **[docs/AGENTS.md](../../../../docs/AGENTS.md) 在层级表、归宿指引行和 slop 清单中命名了该层**，使状态与前瞻类材料有且仅有一个归宿，机制文档则保持无状态标注。其词数上限从 1320 提升到 1435：层级行与指引确实需要这些空间（当前 1361 词，恢复至少 5% 的余量），符合「提升上限须说明理由」的规则。
- **本地草稿目录由 `local-doc` 更名为 `scratch`**，`.gitignore` 与磁盘目录同步更新；它仍是未提交的人工工作材料，与正式文档层相区分。

[文档层级与预算的 Agent Note](2026-07-04-doc-tiers-and-budgets.zh.md) 承载了本决策所扩展的层级体系与预算原理。

## 考虑的替代方案

**以 Agent Note 作为路线图与草案的归宿。** 否决：Agent Note 是以路径编码的单一决策及其替代方案的记录；主题路线图跨越多个仍未定的条目，现状梳理则不记录任何决策，两者都不满足 Agent Note 的骨架与门禁，强行纳入只会让活跃目录充满 spec 式措辞。

**根级纯英文目录。** 否决：本仓库每篇正式的面向人的文档都按统一的配对要求维护双语，且 `docs/**` 之外的目录同时会脱离 `verify-md-links` 与 `verify-md-wrap` 的覆盖——为躲一个门禁而丢掉两个。

**让状态类材料保持不提交。** 否决：团队对现状与方向的共识恰恰是不可见时腐烂最快的内容，且未提交的文件无法被正式文档交叉链接。

**命名为 `docs/plans/`。** 否决：`plan` 已命名 plan 模式包及其日志状态；`roadmap/` 避免让一个运行时术语过载。

## 后果

- 状态、方向与前瞻类内容有了唯一的正式归宿；slop 清单现在会把机制文档的作者指引到该层。
- 该层从空开始：先提交规则与索引，每个子目录随其首篇文档出现。
- 层内每篇文档都要付出双语配对的成本；现状梳理在重测时还需在两种语言中各做一次取代指引的编辑。
- 该目录不会堆积被放弃的草案，因为孵化文件只在需求被积极打磨期间存在。
- 草稿目录更名只触及 `.gitignore` 与未跟踪的本地目录；没有任何已提交内容引用 `local-doc`。
